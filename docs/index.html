Why Ziuf exists

The operating system should work for its user — not watch them.

Ziuf is an independent Linux project focused on privacy, user ownership, modular architecture and engineering claims that match the evidence.

01

Zero telemetry

No automatic reporting of user activity. Diagnostic information is intended to remain local unless the user explicitly chooses to share it.

02

Independent foundation

A controlled source-based Linux foundation, package path and system architecture — not a cosmetic reskin of another distribution.

03

User first

The machine belongs to the person using it. Ziuf aims for understandable controls, familiar Linux conventions and deliberate defaults.

04

Evidence before claims

A milestone is not complete because code exists. Required validation must pass before the project claims the gate.

Privacy position

Local-first by architecture.

Temporary session data is intended not to quietly accumulate after it is no longer needed. Useful crash, boot, service, kernel or hardware diagnostics may remain locally available for troubleshooting.

Ziuf does not plan to upload those logs automatically or treat them as telemetry. Sharing diagnostic information should happen only through an explicit action by the user.

Engineering note: automatic session cleanup remains a design target until its implementation and validation gates pass.

Ziuf Desktop
